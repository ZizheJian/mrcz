\begin{abstract}

High-order finite and spectral element simulations can produce large volumes of data that are costly to store and transfer. Error-bounded lossy compression can reduce these costs while limiting reconstruction error. However, existing compressors are not well suited to high-order element data, whose elements have irregular connectivity but share a common arrangement of points. Specialized approaches may not provide strict pointwise error guarantees, while general-purpose error-bounded compressors do not jointly exploit geometry within elements and statistical regularities across elements.

We present two complementary error-bounded compressors to address these limitations. FDWZ combines distance-weighted multilevel interpolation within each high-order element with a multi-tree Huffman encoding strategy to improve compression ratio while maintaining high throughput. MRCZ represents each element with transform coefficients and residuals, then groups corresponding coefficients across elements to improve compression.

We evaluate FDWZ and MRCZ against SZ3, SZ2, QoZ, ZFP, and SPERR on eight high-order element datasets. At the same PSNR, FDWZ improves the compression ratio over the best-performing baseline by 80.8\% on average in our large-scale experiments. Across the tested error bounds, FDWZ achieves 1.19$\times$ the compression throughput and 1.44$\times$ the decompression throughput of the best-performing SZ3 configuration on average. In end-to-end data-management experiments using Globus to transfer compressed fields between computing facilities, FDWZ matches the fastest baseline on Dataset~4 and reduces total time by 19.2\% on Dataset~5. Meanwhile, at the same PSNR, MRCZ improves the compression ratio over FDWZ by 111.4\% on average, making it suitable when storage reduction is the main concern.

\end{abstract}
